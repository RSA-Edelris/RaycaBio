# Phase 2: Collect confidence scores and rank by cooperativity proxy

## Summary

PROTAC ternary complex predictions (Isambard job 6534300, boltz_series output directory).
Ranked compounds by `pair_chains_iptm["2"]["1"]` (lig→CRBN iptm) as the cooperativity
proxy. Also computed Cα-based ERα surface lysine distances to CRBN for each model_0 PDB.

### Procedure

#### 1. JSON confidence extraction

An inline Python script loaded `confidence_*_model_0.json` for each compound from
`boltz_series/<ARV_NNN>/boltz_results_*/predictions/*/`. Keys extracted:
`confidence_score`, `ptm`, `iptm`, `ligand_iptm`, `protein_iptm`, `pair_chains_iptm`.
Chain index assignment: 0 = ERα, 1 = CRBN, 2 = ligand (confirmed by matching
`pair_chains_iptm["2"]["0"]` against `ligand_iptm`; they are identical for all compounds).
Cooperativity proxy = `pair_chains_iptm["2"]["1"]`.

#### 2. Cα geometry extraction

A second inline script parsed model_0 PDB files for each compound using Cα atoms only
(chain A = ERα, chain B = CRBN, chain C = ligand heavy atoms). Computed: ERα–CRBN Cα
centroid distance, nearest CRBN Cα to each of LYS66/153/171/196/224 NZ atoms.

| Field | Value |
| :--- | :--- |
| Compounds | 10 of 10 parsed successfully |
| Reference comparison | ARV-471 job 6465991 model_0: lig→CRBN iptm = 0.2306 (confirmed from existing JSON) |

## Verification

**10/10 JSONs parsed.** The inline extraction script printed one result row per compound
with no "MISSING" warnings. All 10 `confidence_*_model_0.json` files were present and
contained the expected key set (confirmed by printing `Available JSON keys` for ARV-001).

**Chain index cross-check.** `pair_chains_iptm["2"]["0"]` = `ligand_iptm` for every
compound (e.g. ARV-001: both = 0.9195; ARV-004: both = 0.9600). This confirms chain 2 is
the ligand and chain 0 is ERα, so chain 1 = CRBN.

**Reference ARV-471 lig→CRBN iptm confirmed.** Loaded directly from
`boltz_out/boltz_results_ARV471_ERalpha_CRBN_boltz_input/predictions/.../confidence_..._model_0.json`:
value = 0.2306. All Δ values in the ranking table are relative to this confirmed value.

**Independent cross-check.** Scores produced by the inline script match those from
`analyze_protac_series.py` (background task bymr9kz1y, exit code 0) to 4 decimal places.

## Limitations

- Model_0 only was analysed per compound. Models 1 and 2 were not parsed.
- CRBN orientation is unconstrained (no-MSA mode); surface lysine distances reflect the
  specific random ternary geometry generated by Boltz-2, not a physically constrained result.
- ARV-010 ETKDGv3 failure means its scores are unreliable (noted in results).
